# AGENTS.md

## Отчет (report/)

- При переносе многострочных формул, если строка заканчивается знаком `=`, следующая строка тоже должна начинаться с `=`.
- Цитирования и список литературы должны идти в порядке первого упоминания в тексте.
- При использовании цитирований ставь неразрывный пробел `~` перед ссылкой, чтобы `[<number>]` не переносился отдельно, например: `текст~\cite{key}`.
- Нумерованные списки оформляй так:
  - номер со скобкой: `1)`, `2)`, `3)`;
  - пункт начинается с маленькой буквы;
  - в конце каждой строки ставится `;`.
