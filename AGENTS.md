# AGENTS.md

## Отчет (report/)

- При переносе многострочных формул, если строка заканчивается знаком `=`, следующая строка тоже должна начинаться с `=`.
- Цитирования и список литературы должны идти в порядке первого упоминания в тексте.
- При использовании цитирований ставь неразрывный пробел `~` перед ссылкой, чтобы `[<number>]` не переносился отдельно, например: `текст~\cite{key}`.
- Нумерованные списки оформляй так:
  - номер со скобкой: `1)`, `2)`, `3)`;
  - пункт начинается с маленькой буквы;
  - в конце каждой строки ставится `;`.

### Список литературы (`report/biblio.bib`)

- Каждый источник — отдельная запись `@misc{key, note = {...}}`.
- Записи идут в порядке первого упоминания в тексте.

**Статья** (журнал, сборник, конференция):
```bibtex
@misc{key,
  note = {Автор1, Автор2.
	Название [Электронный ресурс] // Название издания. — Год. — P.~X--Y. — URL:~\detokenize{url}}
}
```
Если есть том и номер: `Vol.~X. No.~X. — P.~X--Y.` (точка после Vol и No, без запятых).

**Книга** (монография, учебник, препринт):
```bibtex
@misc{key,
  note = {Автор1, Автор2.
	Название [Электронный ресурс]. — Год. — URL:~\detokenize{url}}
}
```

- Авторы — фамилия и инициалы через запятую, в конце точка. Каждый автор с новой строки с табуляцией.
- Если авторов много, допустимо `et al.` после перечисления основных.
- Год, страницы (P.), ссылка (URL) — через `. — `, в конце точка.
- Ссылку оборачивать в `\detokenize{...}`.
